# MAD RUST — сайт проекта MAD PROJECT

Лендинг: `index.html`, стили `styles.css`, скрипты `script.js`, арты — векторные сплэши из лаунчера (`assets/art-*.svg`).

## Что где
- `index.html` — вся разметка (навигация, hero, marquee, о проекте со статус-панелью, фичи, 3 шага, блок скачивания, FAQ, футер).
- `styles.css` — тёмная фиолетово-янтарная тема, адаптив (1100 / 900 / 640 px).
- `script.js` — таймер до вайпа (5.11.2026 18:00 МСК, дальше автоматически +14 дней), прогресс-бар скролла, reveal-анимации, «живой» пинг, аккуардеон FAQ, мобильное меню.
- `MAD RUST.exe` — лаунчер для кнопки «Скачать».

## Локальный просмотр
```powershell
cd MAD_RUST_Site
python -m http.server 8741 --bind 127.0.0.1
# http://127.0.0.1:8741/
```

## Публикация
Загрузить содержимое папки на любой статический хостинг (GitHub Pages, Netlify, VPS с nginx) — сборка не нужна, это чистые HTML/CSS/JS.
